Tools Cache Mount

Container running

Tools Cache Mount shares one set of heavyweight caches — Docker build caches, Ollama models, npm packages, Hugging Face downloads — across every machine on your Tailscale, VPN, or LAN via NFS, so each model or dependency is downloaded once and reused everywhere.

Heads up: this container is informational only. NFS mounts must be configured on the host (your Mac, Linux box, or the Hub appliance itself) using the shell scripts in the CI-Tools-Cache-Mounts repository — a container cannot create host mounts. This page serves as the install confirmation and quick reference.

Default cache layout

CacheServer exportLinux mountmacOS mount
docker/srv/cache/docker/mnt/cache/docker/Volumes/cache-docker
ollama/srv/cache/ollama/mnt/cache/ollama/Volumes/cache-ollama
npm/srv/cache/npm/mnt/cache/npm/Volumes/cache-npm
huggingface/srv/cache/huggingface/mnt/cache/huggingface/Volumes/cache-huggingface

Quickstart (run on each client host)

# 1. Get the tooling
git clone https://github.com/companionintelligence/CI-Tools-Cache-Mounts.git
cd CI-Tools-Cache-Mounts

# 2. Point it at your cache server
cp cache-mounts.conf.example cache-mounts.conf
#    edit cache-mounts.conf: set CACHE_SERVER (and optionally CACHE_NAMES)

# 3. Install auto-mounts
./scripts/linux_install.sh   # Linux: fstab entries + mounts now
./scripts/macos_install.sh   # macOS: launchd job + mounts now

# Manual control
./scripts/linux_mount.sh     ./scripts/linux_unmount.sh
./scripts/macos_mount.sh     ./scripts/macos_unmount.sh

Configuration (cache-mounts.conf)

CACHE_SERVER=cache-server.local        # hostname or IP on your VPN/LAN
CACHE_EXPORT_BASE=/srv/cache           # export root on the server
CACHE_NAMES="docker ollama npm huggingface"

# Optional per-cache overrides:
# CACHE_EXPORT_HUGGINGFACE=/srv/cache/hf
# CACHE_MOUNT_HUGGINGFACE=/mnt/cache/huggingface

Point your tools at the shared caches

export OLLAMA_MODELS=/mnt/cache/ollama          # Ollama models (Linux)
export HF_HOME=/mnt/cache/huggingface           # Hugging Face (Linux)
npm config set cache /mnt/cache/npm             # npm
# Docker/BuildKit: --cache-to/--cache-from type=local on /mnt/cache/docker
